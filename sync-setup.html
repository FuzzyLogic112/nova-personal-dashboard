BOOKMARK SYNC · LOCAL ONLY

收藏一次，
工作台自动跟上。

为这台电脑的 Edge / Chrome 安装配套扩展。新增、改名、移动、删除收藏后，工作台会自动更新；关闭工作台也没关系，下次打开会重新读取最新收藏。

下载 NOVA 收藏夹同步扩展 ↓v1.0.0 · 免费开源 · 无需账号或服务器

  1. 下载并解压

    将压缩包解压到一个长期保留的文件夹，例如 D:\NOVA\。展开后会看到 nova-bookmark-sync 文件夹，里面有 manifest.json。安装后请保留该文件夹。

  2. 在浏览器中加载扩展

    在 Edge 地址栏输入 edge://extensions（Chrome 使用 chrome://extensions）。开启「开发人员模式」，点「加载解压缩的扩展」，选择包含 manifest.json 的 nova-bookmark-sync 文件夹。

  3. 打开工作台，确认已连接

    扩展安装后会打开工作台。在「收藏知识库」中看到「收藏夹自动同步已连接」与收藏数量，即已完成。若原工作台已打开，请刷新一次；有旧版缓存时按 Ctrl + Shift + R。

首次同步会在当前浏览器中备份原有工作台收藏。同步以浏览器收藏夹为准，不会修改浏览器收藏夹。可以随时「暂停同步」或「恢复同步前备份」。

扩展只读取收藏夹，并向你的 fuzzylogic112.github.io/nova-personal-dashboard/ 页面发送本地消息。不读取浏览历史、密码或 Cookie，也不上传收藏夹。只同步 HTTP / HTTPS 网页；浏览器内部页、文件地址和脚本书签会跳过。隐私模式不在此版本的支持范围内。

如果未连接：确认扩展已启用、站点访问权限允许此工作台，然后刷新工作台并点击「检查连接」。扩展的「立即同步」表示已读取浏览器收藏；工作台中的同步时间表示已写入本地知识库。

查看扩展源码 · 此安装包仅适配你的 NOVA 地址。换浏览器、浏览器配置文件或电脑后，需要在对应环境重新安装。
